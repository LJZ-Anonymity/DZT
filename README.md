# DZT 模组

这是按照朋友想法写的难度增强模组

## 基础改动

- [x] 所有敌对单位接触伤害在传奇难度的基础上提高20%，弹幕伤害提高40%

> - 单开一个难度

- [ ] 召唤boss时如果玩家身上有药水增益，boss获得20%的效果

> - 召唤药水增加负面效果，使召唤物有概率攻击落空
> - 箭术药水，boss增伤，弹幕速度加快
> - 暴怒药水，boss有概率两倍伤害
> - 魔能药水，boss增伤

## BOSS改动
### 史莱姆王

- [x] 初始体型为原来的50%，体型随血量降低变大，最大为原体型200%，移动速度随体型增大而变快（与原来移动速度随体型减小变快一致）

- [x] 召唤的蓝史莱姆具有10%伤害减免并有33%概率反弹射弹

- [x] 召唤的尖刺史莱姆发射尖刺的频率加快50%

### 克苏鲁之眼

- [x] 冲刺距离将在50%，75%，100%，125%，150%（原最大冲刺距离）随机，每三次冲刺中有一次冲刺会预判玩家的移动方向和速度

- [x] 一阶段生成的小克眼变为7只，二阶段变为11只

- [x] 克苏鲁之眼在冲刺时获得20%伤害减免并有25%概率反弹射弹

### 世界吞噬者

- [x] 所有体节防御+4

- [ ] 体节发射弹幕概率较传奇难度提升50%

- [ ] 身体体节能在背景墙前发射弹幕

- [x] 世界吞噬者召唤的噬魂者防御+4，血量2倍

- [x] 尖钉球造成的伤害减少20%

- [x] 每体节为BOSS增加1%减伤

- [ ] 八字形旋转体术给玩家框起来，不钻进去全屏烧咒火，钻进去里面刷腐化小怪，左边刷腐化者右边刷腐化史莱姆，躲小怪的时候体节还要预判魔唾液

### 克苏鲁之脑

- [x] 防御+9，伤害较传奇难度+10%

- [x] 生成时具有50只飞眼怪

- [x] 二阶段反转左右键

### 蜂王

- [x] 具有0.75的初始激怒系数

- [x] 发射的毒刺速度提升至24，毒刺射向玩家的精准度增加33%

- [x] 冲刺时获得15%伤害减免

### 骷髅王

- [x] 召唤的暗黑法师无敌，无接触伤害

- [x] 暗黑法师发射的弹幕将在可摧毁和不可摧毁之间循环

- [ ] 暗黑法师发射的弹幕可以反弹两次

- [x] 暗黑法师每发射五次弹幕将会进行一次传送（允许传送到没有地牢墙的地方）

### 血肉墙

- [x] 禁用重力药水

- [x] 每只饿鬼为血肉墙提供1防御

### 史莱姆皇后

- [x] 全程获得20%伤害减免

- [x] 二阶段发射的凝胶球提升为20个，攻击方向随机

- [x] 有10%几率反弹射弹

### 双子魔眼

- [ ] 魔焰眼二阶段冲刺速度与距离提升20%，转向速度提升50%

- [ ] 两只眼睛发射弹幕数量提升5，冲刺时获得25%伤害减免

### 机械骷髅王

- [x] 每只手为头部提供5%伤害减免

- [x] 不再能摧毁物块

### 毁灭者

- [ ] 体节完全展开前获得99.99%伤害减免

- [ ] 体节加到100节

### 世纪之花

- [ ] 射弹冷却降低30%，触手有30%概率反弹射弹

### 石巨人

- [ ] 每次承受5%伤害就会随机增大或缩小体型（最小为原来50%，最大为原来150%）

- [x] 禁用平台（参考巨鹿）

### 月亮领主

- [ ] 幻影矢再追踪玩家一秒钟

- [ ] 激光加角速度
